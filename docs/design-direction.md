# 룸꾸 디자인 방향

## 방향

- 성격: 차분한 실내 설계 도구. 설명보다 실제 가구와 치수에 시선이 가도록 한다.
- 세계: 밝은 작업실, 무광 목재 가구, 도면의 얇은 선. 앱 배경과 패널은 중립색을 유지한다.
- 중심 장면: 실제 크기로 편집되는 3D 방, 그 상태를 공유하는 2D 평면도.
- 고유한 디테일: 선택한 가구의 cm 치수선과 치수 근거 표시를 같은 언어로 연결한다.

## 화면 기준

4px 간격 체계, Lucide 18px/1.6px 선, 흰 패널과 조용한 경계선, 제한된 테라코타 강조색을 사용한다. 목재·패브릭·녹색 의자 같은 색은 실제 가구에 둔다. 아이콘은 실제 기능이 있는 버튼에 사용하고 이름 또는 접근성 라벨을 붙인다.

왼쪽은 등록·상담, 가운데는 넓은 방 편집기, 오른쪽은 선택한 가구의 치수와 벽까지 거리다. 작은 화면에서는 보조 패널을 접고 편집기 폭을 확보한다. 조작 버튼은 배치 화면을 가리지 않게 모은다.

3D는 생성형 장식 이미지 대신 제품 자체의 실시간 렌더링을 사용한다. 가구 실루엣과 접지 그림자가 읽히고, 2D와 3D의 크기·각도가 일치해야 한다. 움직임은 카메라와 직접 조작에만 사용한다.

문구는 사용자의 행동과 결과를 말한다. 입력 근거가 없는 치수를 ‘실측’으로 표시하거나 추정 정확도를 백분율로 만들지 않는다.
