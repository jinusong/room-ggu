- `npm run verify`: 공용 스킬 연결, JavaScript 구문, 단위 테스트 23개와 정적 빌드 통과. `npm run format:check` 확인.

- 기존 방·가구·다중 공간·JSON·3D 드래그·실행 취소 회귀 흐름도 통과. 카드 선택 검증은 모델 호출을 대체하지 않는 단위·기능 검사임.

- 실제 모델이 벽 색상 요청에 `kitchen/large`를 함께 제안하는 것을 관찰. 요청 문맥에 따라 허용되는 속성을 제한해, 다시 실행했을 때 기존 원룸 4 × 4 × 2.4m는 보존하고 벽만 세이지로 변경됨을 확인. 소파 요청에 언급되지 않은 낮은 높이 제안도 걸러내는 회귀 테스트 추가.
- 모델은 허용된 `ui` 문자열만 선택. 가짜 HTML·다른 범주의 도구·프로토타입 키를 거절하며 카드의 입력·선택·버튼은 앱의 검증된 상태/동작에만 연결.
- 1440×960 데스크톱 및 390×844·320×740 모바일을 확인. 입력창이 뷰포트 안에 있고 가로 넘침 없음. 새 화면 콘솔 오류 0개.
- 외부 서비스의 런타임이나 비공개 구현을 역분석한 작업이 아님. Google Cloud·A2UI·Vercel의 공식 개념/개발 문서에서 컴포넌트 선택과 데이터 바인딩 원리를 참고. A2UI 프로토콜 호환을 구현하거나 주장하지 않음.
- 작은 모델의 모든 대화 정확도를 보장하지 않음. 모델이 잘못된 편집 카드를 고르면 사용자가 카드 내 도구 선택으로 전환할 수 있음. 사진 모델 경로는 유지했으며 이번에는 사진 모델을 다시 다운로드·벤치마크하지 않음.

## v3 공간·가구 확장

- 실제 Gemma 3 1B 로딩 후 방 상담 추론 확인. “거실 가로 5m 세로 4m 천장 2.6m로 바꿔줘. 소파 중심으로 꾸밀 거야.”를 자동 모드에서 방 상담으로 분류하고, 응답 전 즉시 5 × 4 × 2.6m 반영. AI 응답 뒤에도 세 치수와 사용자 설정 출처 보존.
- Gemma는 방 유형 `living`, 크기 느낌 `large`를 반환했으며, 숫자를 반복한 설명은 화면에서 제외. 숫자는 앱이 처리하고 모델의 정성적 단서는 허용된 공간 프리셋으로만 변환. 작은 모델이 항상 유용한 후속 질문을 만드는 것은 아님.
- 방 뒤에 가구를 언급하면 가구 상담으로 잘못 분류하던 경우를 수정하고 단위·브라우저 회귀 테스트에 같은 문장을 추가. 명시적으로 방/가구 상담 대상을 고를 수도 있음.
- 1440×1000 데스크톱, 390×844·320×740 모바일에서 가로 넘침 없음. 모바일 공간·목록·파일 불러오기 접근 확인.
- 여러 공간은 각각 독립된 직사각형 평면. 연결된 주택 도면, 문·창문 편집은 이번 범위에 포함하지 않음. 새 가구 20종 각각의 사진 인식 정확도는 측정하지 않았음.

## 실제 브라우저

Playwright를 통해 로컬 프로덕션 빌드에서 수행했습니다.

- 상담: “두 명이 넉넉하게 앉는 소파야. 깊이 85cm 가로 200cm” → 가로 200/깊이 85 반영.
- 가구 추가, 90도 회전, 복제, 삭제, 실행 취소·다시 실행, JSON/PNG 다운로드, 새로고침 후 복원 확인.
- 2D 가구를 실제 포인터로 드래그하고 실행 취소로 좌표가 복원됨을 확인.
- 2D로 새로고침한 뒤 3D로 전환하는 회귀 문제를 수정. 숨겨진 뷰포트의 0 크기를 무시하도록 하고, 수정 후 실제 3D 포인터 드래그로 가구 좌표 변경 확인.
- 방 크기 변경과 겹침 표시, 잘못된 JSON 거절 후 기존 배치 보존, 정상 JSON 복원 확인.
- 1440×960 데스크톱 및 390×844·320×740 모바일. 가로 넘침 없음. 모바일에서 방 설정·가구 목록·JSON 불러오기 접근 확인.
- 콘솔 오류 0개 확인. 브라우저는 WebGPU adapter 및 shader-f16을 제공함.

## 남은 환경별 확인 범위

모든 모바일 기기·Safari·Firefox·GPU를 검증한 것은 아닙니다. GPU/메모리 부족 시 AI 모델 준비가 실패할 수 있고, 사진 CPU 모드는 기기에 따라 느립니다. 직접 입력·규칙 기반 상담·2D 배치는 별도 모델 없이 작동합니다.

GPU·WebGL·로컬 저장소를 차단한 별도 브라우저 컨텍스트에서도 2D로 열리고 자동 저장 불가 상태를 안내하는 것을 확인했습니다.

실제 네트워크 기록에서 ONNX WASM은 버전이 고정된 jsDelivr 주소로 로드됨을 확인해, 빌드에 중복 포함되던 미사용 26MB WASM 파일을 배포물에서 제외했습니다. 제외 후 사진 추론도 재확인했습니다.
