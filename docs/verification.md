### 자동 검증

- `npm run test:e2e`: Chrome 브라우저 테스트 10개 통과. 확인한 흐름:
  - 첫 화면 대화 중심(시트 폭 380px 이상·높이 800px 이상, 시작 질문, 도구 없음) → 방 설명 → 방 크기 도구 → 입력 즉시 반영 → 마감 비교 도구, 이전 도구 접힘
  - 가구 설명 → 치수 직접 입력 도구(가로 200·깊이 85는 노란 줄자, 높이는 점선) → 점선 초안 → 놓기 → 같은 도구가 놓인 가구로 이어짐 → 회전·삭제·되돌리기 → 새로고침 후 배치와 대화 복원 → JSON 저장
  - 선택한 가구가 입력창 대상이 되어 “가로 140cm로”, “초록색으로”가 그 가구에 적용되고, “침대도 하나 더”는 책상을 바꾸지 않고 새 초안을 만듦
  - 가구 20종·썸네일 20개·검색·규격 선택(6인 식탁 180×90×74)·러그 배치

  - 2D로 저장 후 다시 열어 3D에서 가구 끌기, 2D에서 가구 끌기
  - 모바일 390×844: 대화로 시작, 시트 전체·낮게·절반 전환 중 입력 중인 글 유지와 입력창 화면 안 유지, 놓기 후 도구 막대와 대화 유지, 390·320px 가로 넘침 없음

## 남은 환경별 확인 범위

모든 모바일 기기·Safari·Firefox·GPU를 검증한 것은 아닙니다. GPU/메모리 부족 시 AI 모델 준비가 실패할 수 있고, 사진 CPU 모드는 기기에 따라 느립니다. 직접 입력·규칙 기반 상담·2D 배치는 별도 모델 없이 작동합니다.

GPU·WebGL·로컬 저장소를 차단한 별도 브라우저 컨텍스트에서도 2D로 열리고 자동 저장 불가 상태를 안내하는 것을 확인했습니다.
