# 검증 기록 · 2026-11-10

## 로컬 자동 검증

- `npm run verify`: 공용 스킬 4개와 Claude/Codex 링크, JavaScript 구문, 계산 테스트 9개, 프로덕션 빌드 통과.
- 새 파이프라인 스킬은 공식 `quick_validate.py`로 검증. YAML 의존성은 임시 디렉터리에만 설치.
- 회전 가구 SAT, 경계 제한, 중복 ID/잘못된 파일 거절, 단위 변환, 직접 입력 보존, 비현실적인 AI 치수 거절을 확인.

## 실제 브라우저

Playwright를 통해 로컬 프로덕션 빌드에서 수행했습니다.

- 상담: “두 명이 넉넉하게 앉는 소파야. 깊이 85cm 가로 200cm” → 가로 200/깊이 85 반영.
- 가구 추가, 90도 회전, 복제, 삭제, 실행 취소·다시 실행, JSON/PNG 다운로드, 새로고침 후 복원 확인.
- 2D 가구를 실제 포인터로 드래그하고 실행 취소로 좌표가 복원됨을 확인.
- 방 크기 변경과 겹침 표시, 잘못된 JSON 거절 후 기존 배치 보존, 정상 JSON 복원 확인.
- 1440×960 데스크톱 및 390×844 모바일. 모바일 문서 가로폭 390px, 가로 넘침 없음.
- 콘솔 오류 0개 확인. 브라우저는 WebGPU adapter 및 shader-f16을 제공함.

## 실제 모델

- Gemma 3 1B: 공개 모델 로딩과 캐시 재사용, 실제 한국어 추론 확인.
- 초기 자유 치수 생성이 소파 폭 30cm 같은 잘못된 값을 제안해 구조를 수정. 모델은 인원수·크기·깊이·높이 단서를 추출하고 앱이 가정값에 반영함.
- 수정 후 “세 명이 앉을 수 있는 낮은 소파” → 한국어 후속 질문, 가로 220/깊이 기본값 90/전체 높이 65cm 초안 확인. 수치는 제품 통계나 실측값이 아닌 앱의 편집 가능한 가정임.
- SmolVLM 256M q4: 실제 모델 다운로드 및 GPU 추론 확인. 초록색 소파 사진에 “Green velvet sofa with two cushions.” 반환.
- 복잡한 페이지 스크린샷에서는 유용하지 않은 답이 나올 수 있음을 관찰. 가구 단독 사진을 권장하고 유형과 치수는 사용자가 수정 가능.
- 테스트 사진은 임시 파일이며 저장소·배포물에 포함하지 않음.

## 남은 환경별 확인 범위

모든 모바일 기기·Safari·Firefox·GPU를 검증한 것은 아닙니다. GPU/메모리 부족 시 AI 모델 준비가 실패할 수 있고, 사진 CPU 모드는 기기에 따라 느립니다. 직접 입력·규칙 기반 상담·2D 배치는 별도 모델 없이 작동합니다.
